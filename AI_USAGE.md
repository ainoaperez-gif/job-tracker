## AI Tools Used

During the development of my Job Application Tracker, I used ChatGPT to help with different aspects of the project. It provided assistance with portions of the Python and HTML code, identifying programming errors, and organizing the website's layout.

## Examples of Prompts

Some of the questions and requests I made while working on the project included:

1. "How do I establish a connection between Flask and my MySQL database?"
2. "Can you explain why this part of my code isn't working?"
3. "How do I add the create, read, update, and delete features?"
4. "What is a good way to calculate how closely someone's skills match a job?"
5. "How can I make the website's appearance more organized and consistent?"

## What Worked Well

One of the most useful aspects of ChatGPT was its ability to explain problems and suggest possible solutions. It assisted with developing Flask functions, setting up HTML pages, and understanding how the application communicates with the database. It also provided guidance when creating the feature that compares user skills with job requirements.

## Changes I Made

Throughout the project, I configured the database settings and adjusted different sections of code to work with my database structure. When I encountered errors, I reviewed the suggested solutions and tested them in VS Code. I also worked on the appearance of the website and used MySQL Workbench to check that information was being stored and updated properly.

## What I Learned

This project gave me a better understanding of how Python, Flask, and MySQL can be combined to create a functional web application. I became more familiar with handling information submitted through forms, managing database records, and troubleshooting programming issues. I also learned that suggestions from AI tools need to be reviewed and tested before being incorporated into a project.

## Conclusion

Overall, ChatGPT served as an additional resource while I worked on the Job Application Tracker. It was useful for explaining technical concepts, providing coding suggestions, and resolving errors. I tested the main features of the application locally to confirm that they functioned as intended.
